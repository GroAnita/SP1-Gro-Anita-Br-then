# **🏛️ Community Science Museum

** A semester project built with HTML, CSS, and design principles **

### 📌 Project Description

The Community Science Museum is a semester-long project created as part of my Front-End Development studies at Noroff.
The goal was to design and build a responsive, accessible, and family-friendly website for a fictional museum focused on science, exploration, and learning.

This project covers the full process from research and concept development to wireframes, prototyping, and final implementation.
The result is a multi-page website that highlights exhibitions, events, membership benefits, and visitor information.

### 🎯 Project Goals

* Create a complete website based on a brief

* Build a strong visual identity and design system

* Structure content for multiple user groups (families, schools, children, tourists)

* Apply UX principles, wireframing, and prototyping

* Develop a fully responsive layout across mobile, tablet, and desktop

* Practice accessibility, semantic HTML, and good content hierarchy

* Produce consistent branding across all pages

### 🛠️ Technologies Used

* HTML5

* CSS3

* Figma (wireframes, prototypes, design system)

* Google Fonts

* Photoshop (image adjustments)

### 📂 Pages Included

* Home — Introduction + hero section

* Exhibitions — Overview of the museum’s themed exhibitions

* Special Events — Information on workshops, talks, and activities

* Membership — Benefits and membership options

* Visit Us — Practical information, opening hours, location

* Contact — Contact form and visitor support

* Get Involved — Opportunities for volunteering and donations
